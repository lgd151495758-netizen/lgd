# 羽签 Quillmark

在 iPad 上像批注 PDF 一样批注 HTML 网页。目标设备 iPad Air 4（iPadOS 17+），支持 Apple Pencil。

## 当前功能（v0.9 · 升级版画完按住成形与实时变形）

- 导入本地 `.html`（连同 `xxx_files` 资源文件夹）、整个网页文件夹，或输入网址（保存为 `.webarchive`，可离线）
- **网页保持可用**：按钮、折叠展开、标签页、表单、视频照常工作；不再转成 PDF，没有强制分页
- 页面宽度跟随 iPad，横竖屏切换时自动重新排版
- **笔迹挂在网页元素上**：内容展开 / 收起 / 重新排版时，笔迹跟着对应段落移动；元素被隐藏时笔迹一起隐藏；网页结构变化后按文字内容重新找到位置
- Apple Pencil 书写，手指操作网页（点按钮、滚动、缩放、轻点胶带）；Pencil 不会误触网页按钮或触发系统随手写；可切换“手指书写”（此时双指滚动）
- 圆珠笔 / 钢笔 / 毛笔（压感、速度、防抖、预测点）、**实线 / 虚线 / 点线**切换、荧光笔（正片叠底、直线模式）
- **升级版「画完按住成形 + 方案 A 实时变形」**（v0.9）：
  - 画完图形后笔尖停顿约 0.4 秒，轻震动后自动规整为标准数学图形，**不抬笔继续拖动笔尖即可实时变形**
  - **去掉椭圆**：随手画的闭合圆弧一律规整为精准正圆，不再误判成歪椭圆；圆心自动磁吸坐标原点/交点，继续拖动实时缩放半径并磁吸交点
  - **新增抛物线识别**：随手画开口向上 / 向下 / 向左 / 向右的抛物线（$y=ax^2+bx+c$、$x=ay^2+by+c$），自动拟合精准二次曲线并磁吸顶点到坐标系原点 $O$；按住拖动可实时调节开口宽窄、高度，拖过顶点还可一键上下/左右翻转开口方向
  - **精准区分菱形、普通平行四边形与矩形**：竖直菱形与斜置菱形自动规整为四边等长且对角线垂直；普通平行四边形严格保留对边平行等长与原有倾角，不再被压扁成矩形；矩形从角点拖动可独立拉伸长宽比（接近正方形时轻吸附），从边中点拖动可旋转调大小
  - **新增正多边形与智能三角形**：支持正五边形、正六边形（与正圆双向 Chamfer RMSD 竞争，绝不把圆误判为六边形），三角形自动规整等边 / 直角 / 等腰；按住拖笔可围绕中心同步缩放与旋转（0°/90° ±2° 轻阻尼防歪）
  - 线段 / 箭头仅在水平（0°）与竖直（90°）提供超精细吸附（拖动微调容差 ±1.2°），不干扰小斜率画线，并支持端点 / 交点磁吸
- **标准数学图形库 + 平面直角坐标系 + 阴影填充 + 顶点微调**（v0.8 / v0.9）：
  - 工具栏 `图形` 内置 14 种数学高频标准图形：**线段、箭头、直角△、等腰△、等边△、矩形（自动吸附正方形）、平行四边形、菱形、等腰梯形、正五边形、正六边形、圆（圆心拖半径）、抛物线（顶点磁吸原点、臂端可拖翻开口）、平面直角坐标系（带箭头与刻度）**
  - 支持实线/虚线/点线、**半透明阴影填充**（讲求阴影面积题神器，60fps 实时同步大屏）
  - 画完即进入**单手编辑态**（或用图形工具轻点已有图形重新选中）：任意顶点/圆心/坐标轴原点均可单手用笔拖动微调并磁吸交点，顶部浮条一键切换「实/虚/点」「阴影/⊙圆心」「复制」「删除」；控制点与浮条仅 iPad 可见，不投屏给学生，在空白处落笔即自动退出编辑态
- **单手虚拟圆规与解析交点磁吸**（v0.7）：专为站姿单手 Apple Pencil 操作设计，圆规与磁吸准星仅显示在 iPad 上、不投屏给学生（大屏只实时显示画出的线与圆弧）：
  - **圆规**：笔拖针脚 `⊕` 磁吸扎圆心、笔拖对侧 `↔` 精准量半径、`🔒锁半径` 等半径移规作图、笔沿虚线圆周划弧（扫满 345° 自动闭合成整圆）、`⊙圆心` 留点、`○整圆` 一键成圆
  - **解析交点磁吸**：自动计算线-线、线-圆、圆-圆交点与端点/中点/圆心，长按拉线、图形顶点与圆规均可精准磁吸，支持完整尺规作图（垂直平分线、角平分线等）
- **遮盖胶带（讲题利器）**（v0.6）：不透明胶带附着在网页题目/答案上，支持自动水平拉直；任意工具下用手指轻点胶带即可揭开/重新盖住（不干扰撤销栈），支持一键「全盖 / 全揭」
- **激光笔**（v0.6.1）：发光拖尾，落笔期间轨迹常亮保留、抬笔后平滑淡出，4 种颜色，60fps 同步显示在外接投屏大屏上且不污染文档笔记
- 橡皮：精确擦除 / 整笔擦除，可“只擦荧光笔”；Pencil 二代双击切换
- 撤销 / 重做，自动保存；网页里指向其他页面的链接用 Safari 打开
- 旧版本（v0.1）转换的 PDF 文档仍可打开批注
- **投屏全屏无黑边**（v0.5）：用 AirPlay 屏幕镜像（如 OfflineMirror / UxPlay）或线缆投屏时，大屏幕只显示工具栏下方的网页与批注内容，并自动按外接屏比例（16:9 / 16:10 / 3:2 / 4:3）动态扩展显示区域、关闭电视过扫描留边，上下左右铺满无黑边、不拉伸不变形；右上角投屏图标可随时切换「全屏无黑边 / 适应屏幕」与完整镜像

## 编译（无需 Mac，使用 Codemagic）

每次推送到 `main`，[Codemagic](https://codemagic.io) 会按 `codemagic.yaml`：

1. 用 XcodeGen 根据 `project.yml` 生成工程
2. 编译未签名的 `Quillmark.ipa`
3. 在 iPad 模拟器上运行单元测试
4. 把结果发到邮箱；IPA 在 Codemagic 构建页面的 **Artifacts** 里下载

（GitHub Actions 的 macOS 机器经常排不上，`.github/workflows/build.yml` 只保留手动运行。）

## 安装到 iPad（Windows）

1. 安装 [Sideloadly](https://sideloadly.io/) 与 iTunes（来自 Apple 官网的非商店版本）
2. 用数据线连接 iPad，在 iPad 上点“信任此电脑”
3. 把 `Quillmark.ipa` 拖进 Sideloadly，填入 Apple ID，点 Start
4. iPad：设置 → 隐私与安全性 → 开发者模式 → 打开并重启
5. iPad：设置 → 通用 → VPN 与设备管理 → 信任你的 Apple ID
6. 免费 Apple ID 签名 7 天有效，到期后用 Sideloadly 重新安装即可（数据保留）

| `Quillmark/UI` | SwiftUI 界面 |
| `QuillmarkTests` | 单元测试（CI 中运行） |
