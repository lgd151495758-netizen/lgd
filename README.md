# 羽签 Quillmark

在 iPad 上用 Apple Pencil 批注 HTML 网页与 PDF 试卷讲义。目标设备 iPad Air 4（iPadOS 17+），支持 Apple Pencil 与外接无黑边投屏。

## 当前功能（v1.5.0 · 课堂快捷效率与 4GB iPad 稳定性节能升级）

- **课堂高频效率与专注书写（v1.5）**：
  - **4 支自定义快捷笔槽 + 暗黑课件粉笔色**：工具栏内置 4 支一键切换笔槽（默认：**黑实线主推导 / 红实线划重点 / 蓝虚线辅助线 / 粉笔白适配暗黑互动网页**），在任意工具下点击 1 下直达对应画笔配置；选中笔槽后调整颜色/粗细/线型即自动保存，长按可恢复默认；色板同步新增亮黄与粉笔白
  - **双指轻点撤销 / 三指轻点重做**：PDF、HTML 网页、悬浮便签三画布全支持纯手指多指轻点撤销与重做（带震动与仅 iPad 可见的轻量 Toast 提示，不干扰 Apple Pencil 书写与双指缩放滚动）
  - **顶栏专注书写模式**：一键折叠顶部标签栏与工具栏释放最大纵向空间，右上角保留仅 iPad 可见的极简悬浮胶囊（4 支笔槽 / 橡皮 / 撤销 / 投屏冻结 / 一键展开），绝不投屏给学生
- **4GB iPad 稳定性、流畅度与节能底座（v1.5）**：
  - **多标签 LRU 内存休眠 & WebKit 崩溃热恢复**：多开重型 PDF 与互动 HTML 课件时，自动保持最近活跃的 4 个标签常驻并在收到系统内存警告时优雅休眠后台标签（严格保留滚动/缩放/页码与撤销栈，切回无缝复活）；同时监听 WebKit 进程异常退出并自动无感恢复页面与笔迹
  - **后台串行异步落盘**：1 秒防抖自动保存移至专用后台串行队列执行 JSON 编码与原子写盘，彻底消除长卷子密集书写时的主线程微卡顿，并限制全文档快照的撤销栈内存占用
  - **精确橡皮擦 120fps 流畅度重构**：改用无 `sqrt` 的局部 AABB + 段对段平方距离预判与局部细分裁剪（彻底消除全局 1pt 加密导致的点数爆炸与缓存泄漏）、每帧合并 240Hz 采样渲染、CoreAnimation / DOM 最小差分层级排序，以及 `WebInkBridge` 在途 IPC 合并节流，精细擦除与整笔擦除同样丝滑无卡顿
  - **智能节能投屏（默认开启）**：静态 PDF 空闲时自动暂停后台截屏（0fps，滚动/翻页/提交笔迹瞬间唤醒 24fps），互动 HTML 网页在手指操作 canvas/滑块/DOM 时满血 24fps、静止空闲后平滑降至 6fps 保活脉冲（60fps 实时矢量笔迹与激光笔完全不受影响），大幅降低连续上课机身发热与耗电
- **课后留档、高清导出与便携备份（v1.4）**：
  - **带批注一键导出与分享**：编辑器顶栏与文档库长按菜单均可呼出 **`导出与分享`**，支持导出**高清矢量 PDF（带批注）**、**当前页图片（PNG）**与**整份拼接长图（PNG）**，一键发班级微信群、AirDrop 或存「文件」

## 编译（无需 Mac，使用 Codemagic）

每次推送到 `main`，[Codemagic](https://codemagic.io) 会按 `codemagic.yaml`：

1. 用 XcodeGen 根据 `project.yml` 生成工程
2. 编译未签名的 `Quillmark.ipa`
3. 在 iPad 模拟器上运行单元测试
4. 把结果发到邮箱；IPA 在 Codemagic 构建页面的 **Artifacts** 里下载

（GitHub Actions 的 macOS 机器经常排不上，`.github/workflows/build.yml` 只保留手动运行。）

## 安装到 iPad（Windows）

1. 安装 [Sideloadly](https://sideloadly.io/) 与 iTunes（来自 Apple 官网的非商店版本）
2. 用数据线连接 iPad，在 iPad 上点“信任此电脑”
3. 把 `Quillmark.ipa` 拖进 Sideloadly，填入 Apple ID，点 Start
4. iPad：设置 → 隐私与安全性 → 开发者模式 → 打开并重启
5. iPad：设置 → 通用 → VPN 与设备管理 → 信任你的 Apple ID
6. 免费 Apple ID 签名 7 天有效，到期后用 Sideloadly 重新安装即可（数据保留）
